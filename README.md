# Doctor Portfolio Website Template

A clean, modern, fully mobile-responsive doctor portfolio website template built with HTML5, CSS3, JavaScript, and Bootstrap 5.

## Folder Structure
```text
doctor_portfolio/
│
├── index.html         # Main homepage with Home, About Me, Chamber, Get Appointment
├── css/
│   └── style.css      # Custom styling and responsive rules
├── js/
│   └── main.js        # Form handling and interactive scripts
└── images/            # Folder for doctor photos, banners, etc.
```

## Features
- **Header Navigation:** Home, About Me, Chamber, and Get Appointment button.
- **Mobile Responsive:** Built using Bootstrap 5 grid system and responsive navbar.
- **Appointment Booking Form:** Interactive form with success message confirmation.
- **Chamber Details:** Cards displaying multiple chamber locations, timings, and contact numbers.

## How to Run
1. Extract the ZIP file.
2. Open `index.html` in any web browser or use Live Server in VS Code.
3. Replace sample images in `images/` with actual doctor photos.
